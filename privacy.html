갈무리

개인정보처리방침

시행일: 2026년 9월 30일

갈무리는 윈도우에서 화면을 캡처하고 녹화하는 프로그램입니다. 이 방침은 갈무리가 어떤 정보를 다루고, 어디에 두며, 어떻게 지울 수 있는지 설명합니다.

1. 모으는 정보

갈무리를 만든 사람은 사용자의 개인정보를 모으지 않습니다. 갈무리에는 따로 운영하는 서버가 없으며, 사용 기록·통계·광고 추적 정보를 어디로도 보내지 않습니다.

2. 컴퓨터에 저장되는 정보

캡처한 이미지와 영상, 태그, 메모, 캡처 속에서 인식한 글자, 캡처한 프로그램과 웹 페이지의 이름·주소는 모두 사용자의 컴퓨터에만 저장됩니다.

  • 보관함 폴더(기본: 사진\갈무리)
  • 설정 폴더(%APPDATA%\갈무리)

글자 인식도 컴퓨터 안에서만 처리하며, 이미지를 외부로 보내지 않습니다.

3. 구글 드라이브 백업 (사용자가 켠 경우에만)

설정에서 사용자가 직접 '구글 계정 연결'을 누른 경우에만 동작합니다. 켜지 않으면 갈무리는 구글과 전혀 통신하지 않습니다.

요청하는 권한은 하나뿐입니다.

  • https://www.googleapis.com/auth/drive.file — 갈무리가 만들었거나 연 파일에만 접근할 수 있습니다. 구글 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.

이 권한으로 갈무리가 다루는 구글 사용자 데이터는 다음과 같습니다.

  • 연결한 구글 계정의 이메일 주소: 어떤 계정에 연결됐는지 설정 화면에 보여 주는 데만 씁니다.
  • 구글 드라이브 저장 공간 사용량: 남은 공간을 설정 화면에 보여 주는 데만 씁니다.
  • 갈무리가 만든 '갈무리 보관함' 폴더와 그 안의 파일(캡처 파일과 태그·메모가 담긴 색인 파일): 백업과, 새 컴퓨터에서 되살리는 데만 씁니다.

이 데이터는 사용자의 컴퓨터와 구글 드라이브 사이에서만 직접 오가며, 다른 서버를 거치지 않습니다. 누구와도 공유하거나 팔거나 넘기지 않고, 광고에 쓰지 않으며, 사람이 열어 보지 않습니다.

로그인은 구글의 페이지에서 이루어지며 갈무리는 비밀번호를 보거나 저장하지 않습니다. 구글이 내어 준 접속 열쇠(토큰)는 사용자의 컴퓨터에 윈도우 암호화(DPAPI)로 잠가 저장합니다.

갈무리가 구글 API로 받은 정보를 사용하고 다른 앱으로 옮기는 일은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함해 그 정책을 따릅니다.

4. 연결 끊기와 삭제

  • 갈무리 설정 → 구글 드라이브 백업 → '연결 끊기'를 누르면 접속 열쇠를 지우고 구글에서도 무효로 만듭니다.
  • 구글 계정 관리 → 보안 → '타사 앱 및 서비스'에서도 갈무리의 접근을 언제든 없앨 수 있습니다.
  • 이미 올라간 파일은 사용자의 구글 드라이브에 그대로 남으며, 사용자가 직접 지울 수 있습니다.
  • 갈무리를 지우고 보관함 폴더와 설정 폴더를 지우면 컴퓨터에 남은 정보도 모두 지워집니다.

Summary in English

Galmuri is a Windows screen capture app. It has no server and collects no personal data. Captures, tags, notes and recognized text stay on the user's computer.

Only if the user connects a Google account, Galmuri backs up captures to the user's own Google Drive using the single scope drive.file, which limits access to files Galmuri itself created. It reads the account email and storage quota only to show them in settings. Data travels directly between the user's computer and Google Drive; it is never shared, sold, transferred, used for advertising, or read by humans. The OAuth token is stored locally, encrypted with Windows DPAPI.

Galmuri's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
